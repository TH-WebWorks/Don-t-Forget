
# Don’t Forget — ADHD Operating System Blueprint

## Core Philosophy
Normal productivity apps assume linear thinking and stable focus.  
**Don’t Forget** is built for nonlinear, idea‑heavy ADHD brains.

It exists to:

1. Capture thoughts instantly  
2. Orient your day  
3. Convert ideas → action automatically  

---

# 1) Jarvis Capture System

## Input Methods
- **Voice Capture** — Tap mic → talk → transcribe  
- **Quick Type** — Brain dump input box  
- **Global Hotkey** — Instant capture overlay  

Goal: 2‑second friction max.

## AI Thought Processing
System auto‑classifies entries:

- Task  
- Idea  
- Reminder  
- Meeting  
- Research topic  
- Business opportunity  

Example:

> “Email Ron about documentary site assets”  

Auto‑becomes:

- Task  
- Category: Business  
- Suggested action: Draft email  

---

# 2) Daily Orientation Dashboard

## Today Panel
Mission briefing showing only:

- Critical tasks  
- Meetings  
- Health actions  
- Revenue actions  

No clutter. No backlog noise.

## Energy‑Based Scheduling

ADHD brains run on energy, not time.

Blocks:

- Deep Work  
- Admin  
- Creative  
- Outreach  
- Health  

Tasks are dragged into energy zones instead of time slots.

---

# 3) Idea → Execution Pipeline

## Processing Queue

Captured ideas enter an inbox.

Processing actions:

- Act now  
- Schedule  
- Archive  
- Convert to project  

Example:

> “Build Consultation Wizard upsell feature”

System suggests:

- Project: T&H WebWorks  
- Action: Create Jira ticket  
- Priority: Medium  

---

# 4) Anti‑Procrastination Engine

## Drift Detection

If inactivity detected:

Prompt:

> “You’re drifting. What’s blocking you?”

Options:

- Overwhelmed  
- Distracted  
- Tired  
- Avoiding task  

System suggests corrective actions.

## 5‑Minute Ignition

Button: **Start Momentum**

- Assigns one tiny task  
- Starts 5‑minute timer  
- Breaks paralysis loop
